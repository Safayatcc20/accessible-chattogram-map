# Finish and polish Accessible Chattogram

## Outcome
Deliver a production-quality frontend MVP that preserves every existing route and workflow while adopting the selected Trustworthy Map-First visual direction.

## Work
- Fix the unsupported guide icon, safe place-detail metadata fallbacks, strict form types, and any other build/import issues found during verification.
- Add the existing site navigation to every page with a skip link and restrained footer.
- Refresh the design system with a trustworthy civic palette, clearer typography, stronger focus states, subtle map-line texture, and consistent elevation and motion.
- Rework the home hero around search, the two requested actions, and a dominant live map while keeping mock-data messaging explicit.
- Upgrade map markers and popups with verification, accessibility summaries, freshness, accessible labels, and polished loading states.
- Improve Explore with verification filters, active-filter counts, reset controls, responsive map/list composition, and accessible result announcements.
- Refine place details into grouped accessibility sections with explicit icon-and-text states, freshness information, community evidence, and the requested caution notice.
- Polish the contribution form, preserve mocked submission, include all accessibility features, improve validation and success focus, and clarify unavailable photo upload.
- Refine Guide, About, cards, empty states, and responsive layouts without adding new product scope.

## Verification
- Check every route and navigation target at phone, tablet, and desktop sizes.
- Exercise search, filters, marker popups, details navigation, and form validation/submission.
- Check browser console/runtime errors and run the production build successfully.

## Technical notes
- Keep TanStack Start routing, Leaflet/OpenStreetMap, React Hook Form, Zod, typed mock services, and the current component structure.
- No backend, database, authentication, package upgrades, or replacement architecture.
- Use semantic design tokens and existing UI primitives; respect reduced motion and keyboard/screen-reader access.
